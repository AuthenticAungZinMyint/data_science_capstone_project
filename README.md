# Capstone Project: Predicting the First Landing of SpaceX Falcon-9 

---

## 🎓 IBM Data Science Professional Certificate

This repository contains the capstone project for the **IBM Data Science Professional Certificate**. It represents the culmination of skills and knowledge acquired throughout the specialization, applying data science methodologies to a real-world or simulated problem.

---

## 🚀 Skills & Technologies

This project leverages a variety of Python libraries and data science techniques, including:

* **Core Python & Data Manipulation:**
    * Python 3.x
    * Pandas (for data manipulation and analysis)
    * NumPy (for numerical operations)
* **Data Visualization:**
    * Matplotlib
    * Seaborn
    * **Geo-visualization Libraries:**
        * Folium (interactive maps)
        * Plotly / Plotly Express (interactive charts, including maps)
* **Machine Learning:**
    * Scikit-learn (for various machine learning algorithms, preprocessing, and model evaluation)
* **Database & API:**
    * SQL (for database interaction, if applicable)
    * Flask (for creating a simple web API to serve models or results)
